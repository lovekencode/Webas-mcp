## 🚀 Quick start
 
### 1. Create your Webas account
 
Go to [webas.app](https://webas.app) and sign in with Google.
 
### 2. Connect Webas to your assistant
 
#### Claude (claude.ai or Claude Desktop)
 
1. Open **Customize → Connectors** ([direct link](https://claude.ai/customize/connectors)).
2. Click **Add custom connector**.
3. Fill in:
   - **Name:** `Webas`
   - **Remote MCP server URL:** `https://webas.app/mcp`
4. Click **Add**, then sign in to Webas when asked.
#### ChatGPT
 
1. Open **Settings → Connectors** ([direct link](https://chatgpt.com/#settings/Connectors)).
2. Add a new connector with the URL `https://webas.app/mcp`.
3. Sign in to Webas when asked.
#### Other MCP clients
 
Any client that supports remote MCP servers works. Use this URL:
 
```
https://webas.app/mcp
```
 
### 3. Ask for your website
 
Try a prompt like:
 
```
Using Webas, create a one-page website for my bakery "Chez Lina" in Montreal.
Include our opening hours, a menu section, a photo gallery and a contact form.
Use warm colors and publish it.
```
 
Your assistant builds the site and gives you the live link. ✅
